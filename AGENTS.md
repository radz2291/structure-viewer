# Structure Viewer

Read `README.md` and `AGENT-GUIDE.md` before changing the application or authoring maps.

This is an independent local explanation viewer. VICT is a read-only design/source reference, not an implementation dependency. Do not resume VICT or modify other repositories as part of this app's work.

For map authoring, use the validated CLI/API and an explicit expected revision. Keep stable node IDs and prior history. Read owner notes, preserve them when reconciling changes, cite inspected sources, and distinguish observed facts, inference and proposals. Do not manually rewrite `data/maps` revisions. No public deployment, AI backend or automatic source execution is needed.

For application changes, run the relevant persistence/security tests and production build, then check changed UI behavior in the supported built-in browser. Preserve other apps and their servers. Sandbox loopback and hard-link failures require a narrowly approved normal local run; do not weaken security settings.
